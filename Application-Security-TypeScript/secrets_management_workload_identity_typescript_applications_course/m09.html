Assessment

Choose one answer for each of the ten questions. The passing score is 80% (8 of 10). You may revise your answers and submit again.

1. A production service uses a long-lived API key stored in deployment configuration. The target also supports short-lived workload credentials. Which change most directly reduces exposure from copied credentials?
2. A container moves from a permanent cloud key to workload identity. Which description best captures the resulting authentication flow?
3. A queue worker authenticates with workload identity but can administer every queue and read unrelated secrets. What is the most effective correction?

5. A deployment injects a database password into an environment variable. Which review conclusion is justified?
6. A frontend build substitutes a confidential third-party API credential into TypeScript code. The generated JavaScript is minified. Which correction preserves confidentiality?
7. A production SDK chain can read environment keys, local login files, or workload credentials. What should the code and deployment review require?
8. A database password has rotated, but a running Node.js service still caches the old version and reuses pooled connections. What must the rollout address?
9. A CI/CD platform supports OIDC federation to a cloud provider. Which deployment design best reduces permanent-key exposure while preserving isolation?
10. Which integration test best verifies that production uses its intended identity and handles expired credentials safely without exposing them?
