Assessment

Choose one answer for each of the ten questions. The passing score is 80% (8 of 10). You may revise your answers and submit again.

1. An Express service runs ordinary JavaScript on one event-loop thread. Two requests both await database reads before updating the same account. Which conclusion is correct?
2. Two inventory requests each read stock=1 and later write stock=0 from that snapshot. Both return success. What does the final stock value prove?
3. A repository changes stock with one conditional mutation: decrement only where the unique item matches and quantity is positive. What must its caller do?
4. A developer moves several read-and-write statements into transaction(). What is still required to establish concurrency correctness?
5. An editor submits content based on document version 12. Which write correctly detects a stale edit?
6. A whole-document save fails its expected-version check. Why can automatically substituting the newest version and retrying be incorrect?
7. A client times out after requesting an order and retries; a queue can also redeliver the same logical operation. What supports safe repeat processing?
8. Each of three Node.js replicas protects a database update with its own in-memory mutex. Which limitation remains?
9. A coupon may be redeemed once per account. Redemption records and account credits live in the same relational database. Which design most directly enforces that invariant?
10. Which test best checks that concurrent reservations cannot oversell one available unit?
